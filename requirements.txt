# --- numpy ---
# Earlier drafts of this project pinned numpy<2.1, based on a real
# conflict hit while this codebase still lived in a single Colab
# notebook (numba/cudf in that environment needed numpy<2.1). That pin
# got carried into this file, but was verified live against a real
# Colab session (2026-08-27) to be actively WRONG for the current
# environment: it forced pip to backtrack all the way down to
# whisperx 3.7.0 to satisfy it, which pulled in a years-old
# pyannote.audio that calls a torchaudio API (AudioMetaData) removed in
# torchaudio 2.2+ -- crashing on import before the pipeline could run
# at all. Upgrading pyannote.audio by hand only moved the mismatch
# (old whisperx calling a renamed pyannote argument next); the actual
# fix was removing this ceiling and letting whisperx's own dependency
# resolution pick a consistent, modern set on its own.
#
# Confirmed working end to end, against real audio, via `pip freeze`
# after a real successful run: numpy 2.5.2, whisperx 3.8.6,
# pyannote-audio 4.0.7 (pulled in automatically as whisperx's own
# dependency -- no need to pin it directly), torch/torchaudio 2.8.0.
